# Labs

Репозиторій з лабораторними роботами з Java.

## Структура

- `Lab1/`: Сучасні можливості Java та підхід Data-Oriented Programming (DOP)
- `Lab2/`: Збірка проєкту за допомогою Gradle та робота з Java Collections Framework
- `Lab3/`: Stream API, Gatherer

Кожна лабораторна лежить у своїй папці і має власний `README.md` з варіантом, інструкцією запуску і результатами.
